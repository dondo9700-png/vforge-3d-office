# VFORGE 3D 오피스

VFORGE의 AI 팀과 함께하는 클레이 질감 **3D 미니어처 오피스**입니다.
Three.js(ES Module + CDN)만으로 만든 단일 페이지 웹 앱이라 빌드 없이 GitHub Pages에서 바로 돌아갑니다.

🔗 **라이브**: https://dondo9700-png.github.io/vforge-3d-office/

## 무엇이 들어있나

- **공간**: 따뜻한 우드 바닥·크림 벽 아이소메트릭 컷어웨이 방, 창문·화분·책장·커피바·스트링 라이트·펜던트 조명
- **데스크존**: 대표(장원님) 듀얼 모니터 자리 + 팀원 책상 5개 + "새 팀원 자리"
- **회의존**: 원형 테이블·의자 6개, 테이블 위 **파란 전화기**(펄스 표시)
- **휴게·충전존**: 노란 소파, 빈백 2개, 안마의자, 플로어 램프
- **화이트보드**: CanvasTexture로 팀원 10명의 상태·에너지와 오늘 실적이 실시간으로 다시 그려지는 현황판
- **캐릭터 10명**: 장원님(대표), VFORGE실장(파란 ㅂ 마스코트, 눈 2개), 블로그 매니저, 스레드·인스타 매니저, 크몽·당근 견적 매니저, 유튜브·영상 PD, 웹·코드 개발자, Claude, ChatGPT, Gemini — 각자 생김새·머리·소품이 다릅니다

## 인터랙션

| 동작 | 결과 |
| --- | --- |
| 📞 전화기 클릭 / 하단 `회의 소집` | AI 팀원 6명이 자리에서 일어나 회의 테이블로 걸어와 앉고, 말풍선으로 브리핑을 주고받습니다. 다시 누르면 복귀 |
| 자동 에너지 루프 | 에너지가 임계치 아래로 떨어지면 빈백·안마의자로 걸어가 충전하고, 완충되면 자기 자리로 돌아옵니다 |
| 📋 화이트보드 클릭 / `현황판` | 팀원 10명의 상태·에너지·오늘 실적을 담은 현황판 오버레이 |
| 캐릭터 클릭 | 역할·현재 작업·에너지 상태 카드 + 말풍선 |
| 드래그 / 휠 / 핀치 | 360° 회전·확대 (OrbitControls, 모바일 터치 지원) |
| 카메라 프리셋 | 전체 / 회의실 / 휴게실 / 화이트보드 |

## 구조

```
index.html          화면 마크업 + HUD + importmap
css/style.css       UI 스타일 (모바일 대응)
js/lib.js           클레이 질감용 지오메트리·머티리얼 헬퍼
js/data.js          팀원 10명, 좌석·휴게 스팟, 회의 대본
js/characters.js    캐릭터 빌더 (휴먼 / ㅂ 마스코트 / AI 파트너)
js/room.js          방·가구·화이트보드·전화기 빌더
js/main.js          씬·조명·상태 머신·인터랙션·카메라
```

`세션·데이터 없음` — 정적 파일만으로 동작합니다.
